# Contributing

Contributions are welcome through issues and pull requests.

1. Run `flutter pub get`.
2. Keep native source updates separate from wrapper changes.
3. Run `flutter analyze`, `flutter test`, and the native build available on your
   host.
4. Update `CHANGELOG.md` for user-visible changes.

Do not commit lock files, generated build output, downloaded models,
credentials, or nested Git repositories. Changes that reduce application
security or privacy will be declined.
